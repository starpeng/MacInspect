# Design

## App icon

The MacInspect app icon was **generated with Google Gemini**, then cropped and resized into `src/Assets.xcassets/AppIcon.appiconset/` (plus preview `AppIcon-1024.png` in this folder).

### Prompt

```text
A 3D macOS app icon for "MacInspect", clean front-facing view, centered composition. The icon is a single rounded squircle container with a brushed aluminum texture and a vibrant emerald green outer glass edge. Inside the squircle is a dark screen displaying an exposed multi-layer computer processor chip, illuminated by a bright cyan holographic scan grid. Micro-engraved technical text "MACINSPECT" is cleanly debossed on the bottom metal frame. Isolated object on a flat solid white background, high contrast studio lighting, zero extra shadows on the floor, modern Apple design language.
```
